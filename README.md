# LikeKerr

**Run fast, like your favourite soccer player.**

LikeKerr turns a recorded footballer's match workload into a personalised, HR-synchronised treadmill training experience.

## Product tracks

- **LikeKerr App / Accessible** — phone/TV + HR tracker + app-controlled forward treadmill.
- **LikeKerr MR** — reconstructed match in VR/MR, using the phone as the BLE/control hub.
- **LikeKerr Research** — hypotheses, experiments, measurements, and results published alongside the build.
- **LikeKerr ODT R&D** — later omnidirectional locomotion research.

## Current milestone

**M001 — Run one real football match**

Select one player trace from one match, derive a target effort rhythm, connect a real HR sensor, drive a treadmill adapter, calculate HR Sync live, record the session, and render the same session in an XR client.

See `specs/M001-run-the-match.md`.
