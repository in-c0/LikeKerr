# XR client

Unity 6 + OpenXR.

M001 is intentionally a **read-only training presentation client**:
- receive session telemetry over LAN;
- render 3D pitch;
- render selected-player position/ghost;
- display player effort, target HR, actual HR, HR Sync and upcoming changes;
- support VR/MR presentation.

No actuator commands originate here.
