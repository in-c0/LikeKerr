# Mobile control hub

Recommended MVP direction: native-capable mobile client that can own simultaneous BLE HR + treadmill connections and keep the session/control loop local.

Responsibilities:
- HR pairing/stream;
- treadmill pairing/control;
- calibration;
- session clock;
- target planner/controller/safety guard;
- HR Sync UI;
- telemetry recording;
- local-network telemetry server for TV/XR clients.
