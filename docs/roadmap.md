# Roadmap

## M001 — Run one real football match
Accessible end-to-end vertical slice plus XR spectator/runner view.

## M002 — Real treadmill interoperability
Validate one specific controllable treadmill model end to end; quantify command latency, acceleration behaviour and failure modes.

## M003 — Full match session
Complete a full football-match workload with calibration, pauses, substitutions and recovery handling.

## M004 — XR training
Run the same session in Unity OpenXR; compare screen vs XR experience.

## M005 — Reconstruction pipeline
Replace curated tracking input with a reproducible match-to-player-trace pipeline.

## M006 — Directional experiment
Prototype low-speed multidirectional intent + centering; measure added value.

## M007 — Sports ODT research
Progressive walk -> jog -> lateral -> backpedal -> acceleration/deceleration -> athletic running validation.
